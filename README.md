# Meus Jogos Zerados

Site e app para registar os jogos que já terminei.

- Pesquisa de jogos com capa
- Nota de 0 a 10 para cada jogo
- Lista pessoal de jogos zerados, com contador e nota média
- Português e inglês, tema claro e escuro
- Pode ser instalado no celular como app

Dados dos jogos: RAWG (rawg.io)
